# 🐞 Reporte de Bug

## ID

BUG-002

## Título

Los elementos ``<li>`` deben estar contenidos en un ``<ul>`` o un ``<ol>`` en las categorías de productos.

- 🟠 Alta (afecta al usuario de forma notoria)


## Descripción

En el menú horizontal de categorías de productos, los elementos ``<li>`` no están contenidos dentro de un ``<ul>`` o un ``<ol>``, lo que genera errores de accesibilidad; un lector de pantalla no enuncia que está en una lista, no puede enunciar el número total de elementos de la lista ni el elemento actual.

## Pasos para reproducir

1. Abrir la página principal de Sibo https://sibobodycare.com/ en Chrome.
2. Activar el narrador de Windows.
3. Navegar la página hasta posicionarse en el elemento 1 de la lista: "Inicio".
4. Moverse hacia la siguiente categoría de producto hasta llegar a "Mascarilla".

## Resultado esperado

- El narrador indica que el usuario se encuentra posicionado en una lista, indica el número total de elementos y al moverse por la lista indica el número de elemento.

## Resultado obtenido

- El narrador solo indica el nombre de cada categoría.

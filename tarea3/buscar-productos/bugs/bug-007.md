# 🐞 Reporte de Bug

## ID

BUG-007

## Título

El nivel de encabezados solo debería incrementarse en 1 en la página de productos individuales (títulos de productos).

- 🟠 Alta (afecta al usuario de forma notoria)


## Descripción

En la página de productos individuales, los encabezados deben seguir un orden jerárquico correcto, incrementándose solo en 1 nivel a la vez. Actualmente, los títulos de los productos no cumplen con esta regla, lo que puede afectar la navegación y comprensión del contenido por parte de usuarios que dependen de lectores de pantalla. El orden actual genera que ningún título o nombre de producto en la pantalla sea enunciado por el narrador.

## Pasos para reproducir

1. Abrir la página de algún producto de Sibo como https://sibobodycare.com/collections/tonicos/products/tonico-elixir en Chrome.
2. Activar el narrador de Windows.
3. Navegar la página hasta posicionarse en el elemento 1 de la lista: "Inicio".
4. Moverse con Tab por la página y observar cómo el narrador anuncia los encabezados y títulos de los productos.

## Resultado esperado

- El narrador indica correctamente los encabezados y títulos de los productos, siguiendo el orden jerárquico adecuado.

## Resultado obtenido

- El narrador no indica el nombre del producto en la página de cada producto.

## Evidencia

- Video: [bug-orden-encabezados](https://youtu.be/eJasdc3Fi3c)
- Código:

```html
<h3><span>Tónico+Elixir Lavanda</span></h3>
```

## Entorno de pruebas

- Navegador: Chrome 155
- AxeDevTools: mejores prácticas desactivado
- Dispositivo: Escritorio
- Sistema operativo: Windows 11
- URL o versión del sistema: [Sibo Body Care](https://sibobodycare.com/)

## Notas adicionales

- No todos los productos individuales tienen una pantalla con el orden jerárquico incorrecto; algunos pueden tener encabezados correctamente estructurados, pero el problema persiste en varios productos.
- Se recomienda revisar y ajustar los niveles de encabezado en todas las páginas de productos individuales para asegurar una correcta accesibilidad y navegación con lectores de pantalla.

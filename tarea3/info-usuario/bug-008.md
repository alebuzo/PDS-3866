## Descripción

En la pantalla de creación de cuenta, el elemento de hcaptcha no está incluido en puntos de referencia accesibles, lo que dificulta la navegación para usuarios que dependen de lectores de pantalla. Navegar por una página web es mucho más sencillo para los usuarios de lectores de pantalla si el contenido se divide en varias secciones de alto nivel. El contenido fuera de las secciones es difícil de encontrar y el propósito del contenido puede no estar claro.

## Pasos para reproducir

1. Abrir la página principal de Sibo https://sibobodycare.com/account/register en Chrome.
2. Activar el narrador de Windows.
3. Navegar la página hasta la sección de hcaptcha.
4. Intentar interactuar con el hcaptcha usando el narrador.

## Resultado esperado

- El narrador menciona "Privacidad" y "Términos" y debería poder interactuar con el hcaptcha de manera accesible.

## Resultado obtenido

- El narrador menciona "Privacidad" y "Términos" y puede interactuar con el hcaptcha y redirigir a las páginas correspondientes de privacidad y términos.

BUG-002

## Título

Los elementos del carrito de compras deben estar contenidos en puntos de referencia accesibles.

## Descripción

En la pantalla de subtotal, los elementos del carrito no están incluidos en puntos de referencia accesibles, lo que dificulta la navegación para usuarios que dependen de lectores de pantalla.

## Pasos para reproducir

1. Abrir la página principal de Sibo https://sibobodycare.com/ en Chrome.
2. Agregar productos al carrito para que haya elementos en la pantalla de subtotal.
3. Activar el narrador de Windows.
4. Navegar la página hasta la pantalla de subtotal.
5. Intentar navegar entre los elementos del carrito.

## Resultado esperado

- El narrador indica que se encuentra en el carrito y debería poder navegar entre los elementos del carrito de manera accesible.

## Resultado obtenido

- El narrador indica que se encuentra en el carrito y narra los elementos más importantes y el botón de finalizar compra.

## Evidencia

- Sin evidencia disponible en Google Chrome 155 o Firefox 158

## Entorno de pruebas

- Navegador: Chrome 155 / Firefox 158
- Guía de accesibilidad: RGAAv4 / RGAA-9.2.1
- AxeDevTools: mejores prácticas activado
- Dispositivo: Escritorio
- Sistema operativo: Windows 11
- URL o versión del sistema: [Sibo Body Care](https://sibobodycare.com/)

## Notas adicionales

- Todos los elementos del carrito deberían estar contenidos en puntos de referencia accesibles para cumplir con las pautas de accesibilidad.
- Bug reportado por AxeDevTools, no se encontró evidencia en Google Chrome 155 o Firefox 158 con el narrador nativo de Windows; queda en revisión.
